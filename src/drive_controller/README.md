# drive_controller

Нода для перемещения робота по точкам, заданным в config/plan.yaml. Чередуются точки сбора брусков, точки выгрузки, последняя точка - "гнездо".

Стратегия задаётся в виде:

```
drive_controller:
  ros__parameters:
    points:
      - [0.529, 0.045, 0.001,   # x,y,yaw; орехи 
         0.859, 0.003, 0.001,   # x,y,yaw; зона выгрузки
         ...
         0.859, 0.003, 0.001]   # x,y,yaw; гнездо
    point_zones: 
      - ["None", "C", "None"]           # keepout_zone         
    time_until_end: 95                  # длительность матча (секунды)
```

Что делает нода:
- Ждёт активацию Nav2 (AMCL, BT Navigator и др.)
- Установливает начальную позу через топик /initialpose
- Передвигается последовательно по точкам, заданным в config/plan.yaml (происходит в timer_callback)
- Устанавливает занятые зоны в keepout_layer (зоны, куда выгружены орехи)
