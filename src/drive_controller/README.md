# drive_controller

Нода для перемещения робота по точкам, заданным в config/plan.yaml. 

- Автоматическое ожидание активации Nav2 (AMCL, BT Navigator и др.)
- Установка начальной позы через топик /initialpose
- Навигация к последовательности целевых точек, заданным в config/plan.yaml (происходит в timer_callback)
- Устанавливает занятые зоны в keepout_layer
